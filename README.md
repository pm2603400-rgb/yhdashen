# 禦寒大神｜供品越對味，願望越靈驗

單一檔案 `index.html` 的網頁小遊戲。所有圖片、音效都內嵌在檔案裡，沒有後端，丟上任何免費靜態網站空間就能玩。

---

## 一、部署（任選一種，約 1–3 分鐘）

### A. Netlify Drop（最快，不用註冊也能先試）
1. 打開 https://app.netlify.com/drop
2. 把整個 `禦寒大神` 資料夾拖進網頁
3. 馬上拿到一個 `https://xxxx.netlify.app` 網址（登入後可改成好記的名字）

### B. GitHub Pages（網址最穩定）
1. 在 GitHub 建一個新的 repo（例如 `yuhan-dashen`），設為 Public
2. 上傳 `index.html`
3. 到 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`，按 Save
4. 約 1 分鐘後網址會是 `https://你的帳號.github.io/yuhan-dashen/`

### C. Cloudflare Pages
1. 到 Cloudflare 後台 **Workers & Pages → Create → Pages → Upload assets**
2. 上傳這個資料夾，按 Deploy
3. 網址會是 `https://專案名.pages.dev`

> Vercel 也可以：新增專案後直接上傳資料夾，免設定。

## 二、遊戲流程

1. **開場動畫**：點燭火 → 暴風雪＋字幕 → 吸雪聚光 → 金光爆發、雪花化成火星 → 神殿升起、巫女大神降臨 → 「禦寒大神」四字落下、蓋「暖」印（有「跳過」鍵，首頁也能「重播開場」）
2. **採集供品**（25 秒）：左右移動竹籃接住掉下來的供品
   - 雪球：竹籃凍住 1.1 秒
   - 暖暖包：竹籃變大 5 秒
3. **擺上供桌**：從接到的供品挑最多 3 樣，會即時顯示「大神暖意」和預估成功率，大神的表情也會跟著變
4. **許願**：選一個預設願望，或自己輸入（最多 24 字）
5. **擲筊**：聖筊＝成功；笑筊＝可再擲（最多 3 次）；陰筊＝失敗
6. **結果**：成功會抽出上上籤／上籤／中籤，籤詩直式排版，可「保存祈願卡」（1080×1600 PNG，手機會跳出分享選單，可直接傳 LINE）

| 薄荷糖 | −8 | 冰 |
| 香草冰淇淋 | −12 | 冰 |

**隱藏組合**：抹茶三重奏（3 樣抹茶）+12、三寶齊聚（抹茶＋黑巧＋草莓都有）+12、暖呼呼（2 樣熱的）+5、寒氣逼人（每樣冰的）−5。
暖意 = 分數加總＋組合，限制在 0–100。

**擲筊機率**（s = 暖意 ÷ 100）：
- 聖筊 = 10% + 78% × s
- 陰筊 = 60% − 57% × s
- 笑筊 = 其餘（可再擲）

最多擲 3 次的總成功率：暖意 0 → 約 14%、50 → 約 60%、79 → 約 83%、100 → 約 97%（已用 20 萬次模擬驗證，和畫面上顯示的數字一致）。

## 四、想自己改內容

用任何文字編輯器打開 `index.html`，搜尋下列關鍵字：

- `const ITEMS` — 供品名稱、分數、標籤、大神的反應台詞、掉落機率（`w`）
- `function evaluate` — 組合加成規則
- `function odds` — 擲筊機率公式
- `const LOTS` — 籤詩（每首 4 句 × 7 字）
- `const WISHES` — 預設願望按鈕
- `idle:` — 首頁大神隨機講的話
- `dur: 25` — 採集秒數

## 五、注意事項

- **字體**：標題用 Google Fonts 的 Noto Serif TC。如果網路擋掉（例如院內網路），會自動改用系統字體，遊戲照常運作。
- **聲音**：全部用 WebAudio 即時合成，不需要音檔。iPhone 若開著靜音鍵可能沒聲音；右上角喇叭可切換靜音。
- **紀錄**：參拜次數、成功次數、最高暖意存在玩家自己的瀏覽器（localStorage），不會上傳。
- **相容性**：Chrome、Safari（iOS 15+）、Edge、Firefox 最新版；手機直式體驗最佳，電腦可用滑鼠或 ← → 鍵。
- **角色**：巫女大神為原創設計（白衣、緋袴、金色前天冠、梅花髮飾、紅圍巾、手捧抹茶）。
